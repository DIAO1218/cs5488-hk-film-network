# DESIGN — CityU 模板学术汇报

## 来源
品牌元素取自校方模板 `CityUHK_PPT_template_202501.pptx`：封面渐变弧、校徽组合、内容页右上角小徽。
不重绘品牌图形，直接复用模板裁切出的位图。

## 画布与安全区
- 1280 × 720
- 内容页左右安全边距 64px，标题基线 y=76，正文区 y=150–640
- 页脚：右下角 `NN / 08`，y=676；页脚上方 1px 分隔线 #E7E2E4

## 配色（全篇仅用 4 个 hex + 品牌渐变）
| 角色 | 值 | 用途 |
|---|---|---|
| ink | `#1A1A1A` | 标题、正文 |
| muted | `#6B6A66` | 副文、注释、页脚 |
| accent | `#C72A74` | 强调数字、关键判断、进度标记 |
| tint | `#F7F1F3` | 卡片/表头浅底 |
| gradient | `#FC9111 → #EF4662 → #C72A74` | 仅封面与折线/高亮条 |

## 字体（仅 1 个家族）
Arial。标题 34/700，小标 12/700 全大写 + letterSpacing 1.4，正文 15/400 lineHeight 1.55，巨型数字 64/700。

## 版式规则
- 标题块：左对齐，左上角小标（`1 · THE DATASET` 形式）在上，主标题在下；右侧不放装饰。
- 内容页统一：右上角校徽 96×72，不遮挡内容。
- 每页至少一个视觉锚点：≥ 44px 数字，或 ≥ 40% 内容区的图。
- 相邻页版式不重复：封面居中 → 左右分栏 → 上图下表 → 全宽图 → 左图右文 → 右图左文 → 三栏 → 收束。
- 留白 ≤ 35%；卡片最多 3 个横排，且不连续两页同构。
